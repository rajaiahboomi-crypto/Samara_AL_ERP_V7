SAMARA CARE ERP 1.2.3 - LATE MAR ENTRY JUSTIFICATION

1. In Supabase SQL Editor, run: 28_late_mar_entry_audit.sql
2. Upload and replace only these files in the GitHub repository root:
   - app.js
   - service-worker.js
   - index.html
3. Close and reopen the ERP. Tap App update available if shown.
4. Confirm version 1.2.3.

NEW MAR SAFEGUARDS
- Actual Administration Time is entered by staff.
- Entry Recorded Time is captured automatically by the system.
- More than 30 minutes difference is marked Late Entry.
- Late Entry Reason and detailed justification are compulsory.
- Future administration time is rejected.
- Every dose remains a separate insert-only MAR record.
- Today’s MAR displays administration time, entry time and late-entry audit status.

No other ERP module is changed.
