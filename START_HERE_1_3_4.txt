SAMARA CARE ERP 1.3.4 — COMPLETE AUDIT TRAIL

1. Run once in Supabase SQL Editor:
   32_complete_audit_trail.sql

2. Upload and replace only:
   app.js
   index.html
   service-worker.js

3. Close all ERP windows, reopen, and tap “App update available” if shown.

Audit Trail records future activity automatically:
- Patient and employee changes
- Prescription and MAR changes
- Vitals and daily care
- Meals and physiotherapy
- Shift handovers and incidents
- Medication errors and CAPA
- Billing transactions
- Documents and room/bed changes
- Intelligent Report WhatsApp history
- User login and logout

The Audit Trail page includes:
- Date range filter
- Module filter
- User filter
- Success/failed filter
- Search
- Indian date/time format
- Export Excel/CSV
- Admin-only access

Important:
The trigger begins recording after this SQL is run. It cannot reconstruct changes that happened before audit recording was enabled.
