SAMARA CARE ERP 1.3.11 — EMPLOYEE SAVE CONFIRMATION POP-UP

Upload and replace only:
- app.js
- index.html
- service-worker.js

No Supabase SQL is required.

Added for Employees:
- New employee created successfully → fixed green pop-up.
- Employee information/documents updated successfully → fixed green pop-up.
- Create or update failure → fixed red pop-up with the actual error.
- Pop-up appears at the top-centre of the visible screen.
- No scrolling is required.
- It closes automatically after 4.5 seconds or manually with ×.

Existing Patient Edit, Physiotherapy, Daily Care, MAR and other modules are unchanged.
