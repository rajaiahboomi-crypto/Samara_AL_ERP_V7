# Samara Care ERP V5.2 — Accordion Menu Upgrade

No Supabase SQL is required for this interface-only update.

## Upload
1. Replace the existing files in the `Samara_AL_V5` GitHub repository with the contents of this package.
2. Commit the changes.
3. Wait for GitHub Pages deployment.
4. Refresh the live app using Ctrl + Shift + R.

## Menu behaviour
Only the permitted main headings are initially shown. Click a heading to expand its submodules. Opening another heading automatically collapses the previous one. Admin and Manager see all headings; other roles see only their authorised headings and modules.
