# Samara Care ERP V8.2.1 Emergency Restore

1. Delete/replace the current GitHub repository files with this package.
2. Commit the changes and wait for GitHub Pages.
3. Open the site and press Ctrl+Shift+R.
4. If still blank, open browser settings and clear site data for the GitHub Pages URL, then reopen.

No SQL changes are required. This restores the last confirmed working V8.2 application.
